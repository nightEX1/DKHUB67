## DKHUB EggWarpUI v2.8

- แก้บัคออโต้ให้เก็บไข่ **ทีละใบ** และรอผลก่อนย้ายไปใบถัดไป
- ข้าม White Egg, Brown Egg, Cracked Egg, Easter Egg และ Stone Egg
- UI ใหญ่ขึ้น ปุ่มฟังก์ชันขนาดพอดี กดง่าย ไม่เบียดกัน
- `AUTO` เปิด/ปิดวาร์ปอัตโนมัติทุก 60 วินาที
- `WEBHOOK` เปิดช่องกรอก Discord Webhook
- `เลือกไข่แจ้งเตือน` เลือกชนิดไข่ที่จะส่งชื่อ ภาพ และน้ำหนัก
- `รีเฟรช` อัปเดตสถานะ
