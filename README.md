# DKHUB67

## DKHUB EggWarpUI v2.7

v2.7 เปลี่ยนจากหน้ารายการไข่แบบเลื่อน เป็นเมนูปุ่มฟังก์ชัน:

- `AUTO` — เปิด/ปิดวาร์ปหาไข่อัตโนมัติทุก 60 วินาที
- `WEBHOOK` — เปิดช่องกรอก Discord Webhook
- `เลือกไข่แจ้งเตือน` — เปิด/ปิดรายการเลือกไข่สำหรับแจ้งเตือน
- `รีเฟรช` — รีเฟรชสถานะ

โหมดออโต้ข้าม White Egg, Brown Egg, Cracked Egg, Easter Egg และ Stone Egg ส่วน Leaf Egg ยังสามารถพบและเลือกแจ้งเตือนได้

ไฟล์หลัก: `DKHUBV2_2.7.lua`
